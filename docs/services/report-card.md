# Report Card

> **Removed in March 2026.** The scoring system (0–100 scores, category weights, grade mapping) has been replaced by raw metrics. Analysis services still run and persist their results, but no aggregate score is calculated. The frontend surfaces metrics directly: Deaths, DPS/HPS, Buff Uptimes, Consumable compliance, Interrupts, Dispels.

See the [Changelog](../../CHANGELOG.md) entry for 2026-03-20 for details on the replacement.
